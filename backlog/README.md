# Backlog — parked work

Changes that are **eventually bound for production but on hold**. Parked here so
they're preserved and findable without nagging the active radar (e.g. the
prod↔staging drift report).

Each item keeps enough to resume cold: what it is, why it's on hold, where the
source of truth lives, and how to apply it when released.

This is a graveyard-adjacent holding pen, not a preview — nothing here adds a
route or deploys. When an item is released, apply it upstream and delete its
entry (same spirit as PROCESS.md §5 "delete on ship").
